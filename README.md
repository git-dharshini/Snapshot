# Snapshot 📸

**Snapshot** is a simple photobooth web application that lets users capture and view photos directly in the browser.

---

## 🔍 Features

- 📸 Capture photos using webcam
- 🖼️ Display live preview before taking a picture
- 💾 Save or download captured images
- 🎨 Clean and responsive UI using HTML/CSS
- 💡 Built with JavaScript

---

## 🧠 How It Works

The app uses the browser’s **getUserMedia API** to access the webcam.  
Users can click a button to take a snapshot and view it instantly on the page.

---

## 🛠️ Tech Stack

- **HTML** – Structure and layout of the web page  
- **CSS** – Styling, layout, and responsive design  
- **JavaScript** – Webcam access, snapshot capture, and UI interaction
